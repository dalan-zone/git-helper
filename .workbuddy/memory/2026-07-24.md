## Android Gradle 模板（git-helper）
- 给 `.github/workflows/release.yml` 增加 **Sync versionName into gradle.properties** 步骤：解析出 VERSION_NAME 后用 `sed` 写回 `gradle.properties`，并在末尾 commit 步骤把 `git add version.properties` 改为 `git add version.properties gradle.properties`。
- 原因：原本打 tag / 手动触发 CI 时，versionName 只通过 `-PVERSION_NAME` 传给 Gradle（运行时生效），但 `gradle.properties` 源头字段不回写，导致本地不带参构建版本名错位。现同步后仓库与云端一致。
- 注意：CI 只在 `ubuntu-latest` 跑，`sed -i` 不带后缀兼容 Linux。
